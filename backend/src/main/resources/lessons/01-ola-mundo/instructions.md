# Olá, Mundo!

Todo programa Java começa pelo método `main`, dentro de uma classe:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Oi!");
    }
}
```

`System.out.println` imprime um texto e pula uma linha.

## Tarefa
Imprima exatamente: `Olá, mundo!`
