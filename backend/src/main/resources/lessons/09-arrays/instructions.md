# Arrays

Arrays guardam vários valores do mesmo tipo:

```java
int[] numeros = {1, 2, 3};
numeros.length; // 3
numeros[0];     // 1
```

O *for-each* percorre todos os elementos:

```java
for (int numero : numeros) { ... }
```
