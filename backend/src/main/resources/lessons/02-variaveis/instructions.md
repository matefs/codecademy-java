# Variáveis

Variáveis guardam valores. Em Java, todo valor tem um **tipo**:

```java
int quantidade = 3;
String fruta = "maçã";
System.out.println("Tenho " + quantidade + " " + fruta);
```

## Tarefa
1. Crie uma variável `int idade` com valor `25`.
2. Crie uma variável `String nome` com valor `"Ana"`.
3. Imprima: `Ana tem 25 anos` usando as variáveis.
