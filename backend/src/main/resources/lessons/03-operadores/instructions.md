# Operadores aritméticos

Java tem `+`, `-`, `*`, `/` e `%` (resto).

Atenção: divisão entre `int` descarta a parte decimal. `7 / 2` é `3`, mas `7 / 2.0` é `3.5`.

## Tarefa
1. Calcule a área de um retângulo de largura `7` e altura `3` e imprima `Área: 21`.
2. Calcule a média de `8`, `7` e `9` como `double` e imprima `Média: 8.0`.
