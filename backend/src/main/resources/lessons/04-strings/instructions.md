# Métodos de String

`String` é um objeto com métodos úteis:

```java
String palavra = "java";
palavra.toUpperCase(); // "JAVA"
palavra.length();      // 4
```

## Tarefa
Dada `String linguagem = "java";` e `String palavra = "programação";`:
1. Imprima `linguagem` em maiúsculas.
2. Imprima a quantidade de caracteres de `palavra`.
